# NORMIA Homepage Prototype V1.2

## Overview
This prototype specification defines the homepage structure, content and visual components for NORMIA. The design should feel premium, modern and practical, using construction-focused language and a mobile-first layout. It should take cues from Linear, Notion and Apple Enterprise: clean sections, restrained visuals, and clear product purpose.

### Prototype goals
- Communicate NORMIA as a field-forward construction platform
- Use practical, credible copy with minimal marketing language
- Prioritize trust through clear process and product clarity
- Support mobile-first layouts with strong section separation

---

## 1. Hero section

### Headline
Documentation that grows from the work, not from reports.

### Supporting text
NORMIA connects task execution, photo evidence and quality control in the field so teams can deliver FDV-ready documentation as part of the build.

### Layout
- Full-width hero with a narrow content column on mobile.
- Headline at top, subhead below, then a short support list.
- On desktop, a two-column layout: text on the left, visual panel on the right.
- On mobile, stack text above the visual panel.

### Visual component
- Simple device mockup or framed card showing a Field Worker task list with a photo card and a deviation badge.
- The visual style should be flat and modern, with a subtle shadow and minimal detail.
- Use neutral backgrounds with a single accent color for CTA and highlights.

### CTA placement
- Primary CTA button below the support list: “See the Field Worker flow”.
- Secondary text link beneath the button: “Read the platform overview”.

---

## 2. Trust section

### Headline
Built for construction delivery, not for marketing.

### Supporting text
NORMIA is designed for site teams, quality inspectors and project coordinators who need clear evidence from work execution. The platform keeps documentation close to execution and avoids duplicate reporting.

### Layout
- Three-column card layout on desktop.
- On mobile, stack cards vertically with generous spacing.
- Each card should be the same width and height for balanced rhythm.

### Visual component
- Use icon-style symbols for each trust point: a clipboard, a camera/photo, and a delivery package or document.
- Keep icons simple, line-based and aligned with the premium aesthetic.

### CTA placement
- A small link below the cards: “Explore how the workflow stays connected”.
- No heavy CTA here; this is a credibility section.

---

## 3. Value chain section

### Headline
How the NORMIA flow works

### Supporting text
A construction project is only as reliable as the information that follows the work. NORMIA turns execution into a connected chain from task to delivery.

### Layout
- Horizontal step flow on desktop with 5 or 6 items.
- On mobile, a stacked step list with numbered blocks.
- Each step is a compact card with a headline and one line of supporting text.

### Visual component
- Subtle step cards with a soft background and a narrow accent bar or dot.
- Use a clean progression style rather than a decorative illustration.

### CTA placement
- Inline link below the step list: “See the platform modules that support each stage”.
- No button required in this section.

---

## 4. Platform modules section

### Headline
One platform for site work, knowledge and oversight.

### Supporting text
NORMIA groups field execution, asset information and verification into a single operational platform so each project step is captured in context.

### Layout
- Three cards in a row on desktop.
- On mobile, stack cards in a single column.
- Use a consistent card style with title, short description, and a subtle label.

### Visual component
- Each card gets a small module indicator: “Field Worker”, “Knowledge Engine”, “Supervisor”.
- Cards should use tone-on-tone backgrounds and a subtle border.
- Avoid strong illustrations; instead use simple symbolic shapes or minimal icon accents.

### CTA placement
- Optional small link under the cards: “Learn how the modules work together”.
- This section is descriptive, not sales-heavy.

---

## 5. Field Worker showcase section

### Headline
Field Worker: the tool for on-site execution and evidence.

### Supporting text
Field Worker puts the site workflow in one mobile-ready view. The crew sees tasks, captures photos and reports deviations from the same place, so documentation is created at the same pace as the build.

### Layout
- Split layout on desktop with text content on the left and a larger mockup panel on the right.
- On mobile, stack the text above the mockup panel.
- Use a compact vertical rhythm with a headline, paragraph, and three feature bullets.

### Visual component
- A mobile screen mockup showing:
  - a task list with completion checkboxes,
  - a photo capture thumbnail,
  - an “avvik” flag or deviation indicator.
- The mockup should feel like a field tool interface: clean, legible, and direct.

### CTA placement
- Primary CTA under the feature bullets: “Review the Field Worker flow”.
- The CTA should be strong and near the bottom of the section.

---

## 6. Pilot CTA section

### Headline
Talk to us about a site pilot.

### Supporting text
We work with construction teams that want fewer handoffs, better documentation and a smoother path to FDV delivery. Tell us about your project and we will show how NORMIA can fit your workflow.

### Layout
- Centered content with a clear callout box or band.
- Keep the text concise and stack the CTA below the paragraph.
- On mobile, make the button full width with generous padding.

### Visual component
- A minimal callout box with a subtle background difference.
- No illustration required; focus on a clean message area.

### CTA placement
- Large button below the supporting text: “Contact NORMIA for a pilot project”.
- Optional secondary note beneath the button: “info@normia.no”.

---

## 7. Footer

### Headline
No headline needed; use a simple footer layout.

### Supporting text
NORMIA supports documentation and delivery for construction projects.

### Layout
- Two-row footer with navigation links and contact details.
- On mobile, stack links and contact information vertically.
- Use a calm, low-contrast background.

### Visual component
- Minimal styling: subtle horizontal rule above the footer, clean text.
- Include a small NORMIA wordmark or name.

### CTA placement
- Footer includes a small link to Contact and Resources.
- No primary CTA; keep the footer functional and understated.
